# Every string literal of libwolpdt.so (S2 §7.5 "зашифрованные строки").
# The build turns this file into build/generated/wolpdt/wolpdt_strings.h (task
# :devicetrust:generateNativeStrings): each value is stored XOR-ed with its own keystream and is
# decrypted onto the stack only while it is used. :devicetrust:checkNativeStrings fails the
# build if any value of 4+ characters appears in plain text in the packaged .so.
#
# Format: NAME value        — one string, used as OBF_NAME
#         NAME[] value      — next element of the array OBF_NAME (count OBF_NAME_N)
# The value is the rest of the line after the first run of spaces; C escapes \0 \r \n \t \\ work.
# Lists shared with Kotlin (SU_PATHS, EMU_PATHS, EMU_HARDWARE…) must stay identical to
# devicetrust/src/main/kotlin/org/wolpmessenger/devicetrust/rasp/Checks.kt.
